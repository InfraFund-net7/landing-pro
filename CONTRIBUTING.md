# Contributing to InfraFund Landing Pro

Thank you for your interest in contributing! Please follow these guidelines to ensure a smooth review and merge process.

## Definition of Done: Pull Request (PR) Checks

To be considered complete and ready for merge, every PR must meet the following criteria:

1. **Create a Pull Request Using the Template**
   - All PRs must be opened using the provided PR template.

2. **Request Review from Code Owners**
   - After opening your PR, request a review from the code owners listed in the CODEOWNERS file.

3. **Automated and Manual Reviews**
   - Code owners will run reviews using:
     - GitHub Copilot review
     - Gemini review
     - ChatGPT review
     - Manual code review
   - All feedback and required changes must be addressed by the PR author.

4. **Ready to Merge**
   - Once all requested changes are resolved and code owners approve, the PR is ready to be merged.

5. **Passing Checks**
   - All automated checks (CI, tests, linters, etc.) must pass before any reviews and after each push to the PR branch.

6. **PR Template Reminder**
   - These steps are included in the PR template. Please review and check them off as you complete each one.

---

For questions, please contact the code owners or maintainers.
